# Jet Note

**Jet Note** is a simple tool for quickly capturing and organizing your ideas.

You can create text notes and add **images, audio, and videos**. Jet Note also provides online tools such as **Baidu Search, Sentence, and Merriam-Webster Dictionary**.

While browsing the web, Jet Note can detect **images, audio, and video resources** on a page and save them to your device.

Notes can be favorited for quick access, with the **most recently favorited notes appearing at the top**.

In **Settings**, you can:

- Customize the interface color
- Switch between Chinese and English
- Import or export `.jnote` backups
- Reopen the tutorial through **Manual → View Tutorial**

---

## What Makes Jet Note Different?

Unlike traditional note-taking apps, Jet Note combines **note-taking, web tools, and resource collection** in one place.

### Built-in Web Tools

Access **Baidu Search, Sentence, and Merriam-Webster Dictionary** without leaving your note-taking workflow.

### Web Resource Detection

Detect **images, audio, and video resources** while browsing web pages.

### Batch Resource Saving

Save detected media individually, or quickly download all captured resources of the same type.

### Multimedia Notes


[To download it](https://github.com/lei1737524550/Jet-Note/releases/download/Jet_Note_V8.0/Jet.Note.v8.0.6.Beta.apk)

Mix **text, images, audio, and video** in the same note instead of treating them only as separate attachments.

### Portable `.jnote` Backups

Export and import your notes using Jet Note's own `.jnote` backup format.

### Customizable Appearance

Adjust the interface colors directly with the built-in color controls.
