# English

[中文](#中文)

## About Jet Note

**Jet Note** is a simple tool for quickly capturing, organizing, and collecting information.

You can create text notes and add **images, audio, and videos** to your notes. Jet Note also integrates useful online tools such as **Baidu Search, Sentence, and Merriam-Webster Dictionary**.

While browsing the web, Jet Note can detect **images, audio, and video resources** on a page and save them directly to your device.

Notes can also be favorited for quick access. The **most recently favorited notes appear at the top**, making frequently used content easier to find.

## Features

- Create and organize notes
- Add images, audio, and videos
- Favorite important notes
- Built-in online tools
- Detect media resources from web pages
- Save detected resources individually or in batches
- Import and export `.jnote` backups
- Customize interface colors
- Switch between Chinese and English
- Built-in tutorial accessible from **Manual → View Tutorial**

---

## What Makes Jet Note Different?

Unlike traditional note-taking apps, Jet Note combines **note-taking, multimedia content, web tools, and resource collection** in one place.

### Built-in Web Tools

Access **Baidu Search, Sentence, and Merriam-Webster Dictionary** directly within Jet Note without leaving your note-taking workflow.

### Web Resource Detection

Jet Note can detect available **images, audio, and video resources** while you browse web pages.

### Batch Resource Saving

Detected resources can be saved individually, or you can quickly save all captured resources of the same type.

### Multimedia Notes

Combine **text, images, audio, and video** in the same note, allowing a note to contain much more than plain text.

### Portable `.jnote` Backups

Export your notes as `.jnote` backups and import them again when needed.

### Customizable Appearance

Use the built-in color controls to customize the appearance of Jet Note.

---

## In Short

**Jet Note is designed not only for writing things down, but also for finding, collecting, and organizing information and media while you work.**

# 中文

[English](#english)

## 关于 Jet Note

**Jet Note** 是一款用于快速记录、整理和收集信息的轻量化笔记工具。

你可以创建文字笔记，并在笔记中添加**图片、音频和视频**。Jet Note 还集成了 **百度搜索、Sentence 和 Merriam-Webster Dictionary（韦氏词典）**等在线工具。

在浏览网页时，Jet Note 可以检测网页中的**图片、音频和视频资源**，并将需要的资源保存到设备。

笔记支持收藏功能。**最近收藏的笔记会显示在收藏区域最上方**，方便快速找到经常使用的重要内容。

## 主要功能

- 创建和整理笔记
- 添加图片、音频和视频
- 收藏重要笔记
- 内置在线工具
- 检测网页中的媒体资源
- 单独或批量保存检测到的资源
- 导入和导出 `.jnote` 备份
- 自定义界面颜色
- 中文 / English 语言切换
- 通过 **说明书 → 查看教程** 随时重新查看使用教程

---

## Jet Note 有什么不同？

与传统笔记应用相比，Jet Note 将**笔记、多媒体内容、在线工具和网页资源收集**整合在同一个应用中。

### 内置在线工具

无需离开 Jet Note，即可使用 **百度搜索、Sentence 和韦氏词典**等在线工具。

### 网页资源检测

浏览网页时，可以检测页面中可获取的**图片、音频和视频资源**。

### 批量保存资源

除了单独保存检测到的资源，还可以快速保存同一类型的全部已捕获资源。

### 多媒体笔记

在同一条笔记中组合使用**文字、图片、音频和视频**，让笔记不仅局限于纯文字记录。

### `.jnote` 便携备份

可以将笔记导出为 `.jnote` 备份文件，并在需要时重新导入。

### 自定义外观

通过内置颜色控制功能调整 Jet Note 的界面颜色。
