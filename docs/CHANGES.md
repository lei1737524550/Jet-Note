# Jet Note 2.5 修改记录

1. 图片和音乐入口移到说说输入区右侧，使用一致的图标按钮。
2. 新增 Jet Note 自定义 alert 提示层，接管网页 `window.alert()`。
3. 新增“句子”入口，默认打开 `https://soundoftext.com/`，复用词典的原生隔离 WebView 控制器。
4. 删除日志页面、编辑器、脚本、动作面板、i18n 文案、IndexedDB 状态字段和归档字段。
5. 音乐卡片改为文本下方靠右的 Feather 扬声器图标；多音频用 1、2、3 下标区分。
6. 说说菜单改为跟随右上角按钮的紧凑浮层。
7. 顶部用户区和功能栏去除卡片色块背景。
8. 删除自定义背景按钮、图片选择、IndexedDB 存储恢复及背景裁剪分支，页面改用 `rgb(240, 255, 230)` 纯色背景。
9. 顶部头像与名字下移，并将头像底部到功能图标行的垂直间距约束在 60px 内。
10. 修复三点菜单锚点、字符串 ID 编辑失效及音乐附件编辑兼容；删除确认复用相同位置和紧凑尺寸。
11. 设置页引入可复用双框选项组件，语言选中项使用浅蓝色背景。
12. 新增圆形/正方形头像设置；主页、说说列表与裁剪框保持同一形状，默认正方形。
13. 背景设置集中到设置页，支持屏幕比例图片裁剪和 RGB 数值背景，并兼容读取旧图片背景记录。

应用版本更新为 2.5（versionCode 16），包名保持不变。备份协议维持 post-only formatVersion 2，旧 formatVersion 1 不再导入。
