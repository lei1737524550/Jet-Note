# Jet Note 2.5 修改记录

1. 图片和音乐入口移到说说输入区右侧，使用一致的图标按钮。
2. 新增 Jet Note 自定义 alert 提示层，接管网页 `window.alert()`。
3. 新增“句子”入口，默认打开 `https://soundoftext.com/`，复用词典的原生隔离 WebView 控制器。
4. 删除日志页面、编辑器、脚本、动作面板、i18n 文案、IndexedDB 状态字段和归档字段。
5. 音乐卡片改为文本下方靠右的 Feather 扬声器图标；多音频用 1、2、3 下标区分。
6. 说说菜单改为跟随右上角按钮的紧凑浮层。
7. 顶部用户区和功能栏去除卡片色块背景。
8. 删除自定义背景按钮、图片选择、IndexedDB 存储恢复及背景裁剪分支，页面改用 `rgb(240, 255, 230)` 纯色背景。
9. 顶部头像与名字下移，并将头像底部到功能图标行的垂直间距约束在 60px 内。
10. 修复三点菜单锚点、字符串 ID 编辑失效及音乐附件编辑兼容；删除确认复用相同位置和紧凑尺寸。
11. 设置页引入可复用双框选项组件，语言选中项使用浅蓝色背景。
12. 新增圆形/正方形头像设置；主页、说说列表与裁剪框保持同一形状，默认正方形。
13. 背景设置集中到设置页，支持屏幕比例图片裁剪和 RGB 数值背景，并兼容读取旧图片背景记录。

14. 词典与句子工具栏在“获取音频”左侧新增刷新按钮，可重新加载当前网页并清除旧的候选资源记录。
15. 获取音频增加播放期间 URL 记录、原生 WebView 已加载资源、性能资源、媒体标签、懒加载属性和内嵌 JSON/脚本链接六条发现通道，兼容没有标准文件扩展名的音频地址。
16. 获取结果按真实音频资源优先排序，其他候选资源置后并标红，以便在站点资源结构变化时仍可手动选择验证。
17. 播放期资源观察改为双通道：audio/video 已实际加载的 URL 作为已证实音频优先显示；fetch、XHR 和性能资源仅在地址具有音频特征时作为候选记录，避免把普通网页接口误当作音频。
18. 修复候选排序比较器：所有项目均使用布尔音频状态，避免 undefined 转为 NaN 后造成红色候选仍排在第一位；播放链路发现但 URL 没有明确音频特征的二进制中间资源改为红色后置。
19. 词典与句子工具栏移除独立刷新按钮；长按“获取音频”改为刷新当前网页，不再显示网页内悬浮获取按钮；标题采用叠层布局并始终按工具栏几何中心居中。
20. 新建/编辑说说工具栏复用词典页面的 50dp/36dp 视觉规格：标题与按钮字号、圆角、留白统一；采用左右对称区域与中间独立栅格，标题始终按整栏几何中心显示。

应用版本更新为 3.0（versionCode 21），包名保持不变。备份协议维持 post-only formatVersion 2，旧 formatVersion 1 不再导入。
